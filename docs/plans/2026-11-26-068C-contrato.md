## RPCs

`rota_068_problema_marcar({p_cd_pedido,p_obs,p_requisicao})` → `{status:'ok',ativa:true,repetido:false}`.

UID + pode_marcar_rota. Observação obrigatória, espaços normalizados, 1..300 sem `<`/`>`/controles. Pedido precisa ter saída registrada ou confirmação063 antiga ativa. Retry da mesma requisição responde estado atual daquela ocorrência; replay depois do desfazer não recria problema. Novo clique enquanto problema ativo não troca a observação nem duplica a ocorrência.

`rota_068_problema_desfazer({p_cd_pedido,p_requisicao})` → `{status:'ok',alterado:true,repetido:false}`. Somente admin. Retry não desfaz uma ocorrência posterior. Reutilizar UUID em outro pedido/operação retorna `requisicao_invalida`.

Sem permissão: SQLSTATE42501. Validações devolvem `{status:'erro',motivo:'parametro_invalido'|'observacao_invalida'|'pedido_sem_saida'|'requisicao_invalida'}`. Falhas SQL inesperadas são erros reais, nunca sucesso.

`rota_068_entregas({p_desde,p_ate})` → tabela ordenada dia/cd:

```json
[{"cd_pedido":683001,"data_entrega":"2026-11-26","status":"problema","obs":"Caixa avariada","por_nome":"Marcio QA","em":"...","cliente_tipo":"cnpj","cliente_nome":"Cliente QA","documento":"11222333000181","valor_centavos":12300}]
```

`obs/por_nome/em` são nulos no entregue sem problema. Campos extras tipo/nome/documento/valor são snapshot para relatório mesmo após fonte sumir; documento só CNPJ. Equipe e Edge service_role podem ler. Intervalo inclusivo até367 dias; usar `.order('cd_pedido').range(...)`/paginação para não truncar no limite PostgREST. Pedido `alcance='site'` fica fora da RPC.

## UI e contagem

- Vermelho/observação quando status=problema. Só status=entregue conta como entregue.
- Problema **não volta automaticamente para pendentes**. Snapshot continua na projeção063/guarda055; desfazer retorna ao estado entregue.
- Não contornar bloqueios065 para reprogramar uma linha já fechada. Uma nova tentativa explícita de entrega (mover a partir de um plano congelado) exige fluxo próprio; este pacote mantém esse caso isolado, sem reprogramação automática nem alteração de foto histórica.
- `pedidos_dia` usa a RPC canônica para o total da última coluna (Enviou/entregou), exclui problemas/fora-do-site, inclusive quando a fonte ERP sumiu. Erro/ausência de RPC ou de leitura de exclusões interrompe a mensagem. Template aprovado e quantidade de parâmetros permanecem iguais.
